
- Read - Uncommitted: 最低等級，可以讀到 還沒Committed的資料
- Read - Committed: 只能讀其他交易已Committed的資料
- Repeatable - Read(InnoDB Default): 不考慮其他交易修改，同一交易多次`SELECT`結果相同
- Serializable：序列執行

|                                                      | Read - Uncomitted | Read - Committed | Repeatable - Read | Serializable |
| ---------------------------------------------------- | ----------------- | ---------------- | ----------------- | ------------ |
| Dirty - Read<br>:讀到未Commit<br>(別人Rollback, 讀到假資料)    | yes               | no               | no                | no           |
| Non - Repeatable Read<br>:讀到已Commit<br>(讀兩次**結果**不同) | yes               | yes              | no                | no           |
| Phantom Read<br>: SELECT兩次**交易筆數**不同                 | yes               | yes              | yes               | no           |
