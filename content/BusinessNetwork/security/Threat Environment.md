- Malware：惡意軟體總稱

| category      | describe       |
| ------------- | -------------- |
| Virus         | 依賴其他主體         |
| Worm          | 獨立程式，可以自我複製    |
| Trojan Hourse | 偽裝成系統檔，不能自行傳播  |
| Spyware       | 暗中收集資訊給 Trojan |
- 社交型攻擊

| category           | describe                          |
| ------------------ | --------------------------------- |
| Social Engineering | 用心理學等社交技巧，讓User洩漏資訊               |
| Phishing           | 透果假 email誘使 User 洩漏資訊             |
| Spear Phishing     | 針對受害者精心策劃的 Phishing<br>(ex. 假冒上司) |
| Identity Theft     | 非法使用他人資訊取得利益                      |

##### APT (Advanced Persistent Threat)
- 針對組織精心策劃的長期攻擊
- Advanced：技術高明（精心設計的 spear phishing）
- Persistent：持續偵查
