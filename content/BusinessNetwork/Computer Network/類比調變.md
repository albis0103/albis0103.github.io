- 將數位資料以類比訊號表示，假設載波訊號 $A\sin (2\pi ft)$ 
- 以不同方式表示 0/ 1
#### FSK (Frequency Shift Keying)
調整頻率 $f$ 高低表示 0/ 1
- `0`: $A\sin (2\pi f_0t)$
- `1`: $A\sin (2\pi f_1t)$

#### ASK (Amplitude Shift Keying)
調整振幅 $A$ 大小表示 0 / 1
- `0`: $A_0\sin (2\pi ft)$
- `1`: $A_1\sin (2\pi ft)$

#### PSK (Phase Shift Keying)
調整相位角表示 0 / 1
- `0`: $A\sin (2\pi ft + \theta_0)$
- `1`: $A\sin (2\pi ft+\theta_1)$

#### QPSK (Quadrature Phase Shift Keying)
固定振幅，4 種可能相位表示，每個訊號 2 bits，載波訊號 $A\cos (2\pi ft)$
- `11`: $A\cos (2\pi ft + \frac{\pi}{4})$
- `01`: $A\cos (2\pi ft + \frac{3\pi}{4})$
- `00`: $A\cos (2\pi ft + \frac{5\pi}{4})$
- `10`: $A\cos (2\pi ft + \frac{7\pi}{4})$


#### QAM - 16 (Quadrature Amplitude Modulation - 16)
不同振幅 $A$ 跟相位 $\theta$ 構成 16 種組合表示，每個訊號 4 bits
$$A\cos (2\pi ft + \theta) =A_i\cos(2\pi ft)+A_j\sin(2\pi ft)$$
- note : by $\cos(\alpha + \beta) = \cos\alpha\cos\beta - \sin\alpha\sin\beta$
