# 參考答案與評分重點

**一、是非題**

1. X。Defense in depth 中，**任何一個**元件有效就能擋下攻擊。要「所有元件都必須有效」的是 weakest link 的情況。
2. O。Overprovisioning 傳輸線成本高、人力少；priority 傳輸線成本較低，但設定人力較多。
3. X。Trap 是 agent 偵測到問題時，主動發給 manager。
4. X。目標是在經濟上合理的範圍內降低風險，並平衡風險與保護成本。
5. O。單一步驟失敗就能中斷整條 kill chain，所以公司可以在任何一步阻斷。
6. X。Packet 的來源與目的 IP 不變。每換一個網路，路由器就把 packet 放進新的 frame，MAC 位址會變。
7. X。速度的 SLA 保證的是「不低於」某值，也就是最差情況。
8. X。Zero-day 是在 patch 釋出**之前**的漏洞特定攻擊。
9. O。
10. X。企業通常不想移除它，因為集中管理能改善一致性並降低成本。正確做法是找出所有 single points of takeover，並徹底強化防護。

**二、名詞比較（要點）**

1. Defense in depth 是用**一連串不同的**對策，任何一個有效就能擋下攻擊。Weakest link analysis 針對**單一**對策內含多個元件，所有元件都有效才能擋下攻擊，所以要找出最弱的那個。
2. Overprovisioning 是裝多餘的容量，簡單、不增加人力，但傳輸線成本高。Priority 對高需求流量（如 VoIP）給高優先權，低優先權（如 email）等待，成本較低但需要設定人力。QoS reservation 為保證流量預留容量，適合有 QoS 保證的流量，其他流量只能用剩下的，即使保留的容量沒在使用。
3. Get / Set：manager 發出，讀取或修改 agent 的值，由 manager 主動。Trap：agent 偵測到問題時主動發出，由 agent 主動。
4. Single point of takeover：攻擊者一旦攻下，就能控制大片範圍，例如中央防火牆政策伺服器。Single point of failure：故障就造成服務中斷，例如階層式 Ethernet 的唯一路徑。前者是安全風險，後者是可用性風險。
5. Audit 是抽樣檢查公司內的行為是否遵守政策。Vulnerability testing 是在攻擊者之前自己攻擊自己的系統，找出並修補弱點。

**三、簡答與計算題**

1. 路由器把 packet 放進適合下一個網路的新 frame 再送出。Packet 的來源與目的 IP 位址不變（它描述的是整條 route）。Frame 的 header 與 trailer、MAC 位址在每個網路都會換（它只描述一個 data link）。
    
2. 計算：
    
    ||無對策|A|B|
    |---|---|---|---|
    |預期損失|800,000 × 25% = 200,000|400,000 × 25% = 100,000|800,000 × 15% = 120,000|
    |對策成本|0|50,000|70,000|
    |淨預期支出|200,000|150,000|190,000|
    |年度價值|0|+50,000|+10,000|
    
    兩者價值皆為正，都划算，但 A 的淨支出較低、價值較高，應採用 A。
    
3. Agent 在 switch 上，偵測到 port 故障後主動發出 Trap 給 manager。Manager 收到後，可用 Get 讀取該 switch 的 MIB 中相關數值（如介面狀態）確認。必要時用 Set 修改設定。Agent 的資訊儲存在 MIB，管理員用它掌握網路狀況。
    

**四、申論題（要點）**

- **A.** 入侵過程：魚叉式釣魚信入侵供應商，竊取憑證，用憑證進入 Target 網路，在 POS 安裝惡意軟體，竊取信用卡資料。Kill Chain 七步：Recon、Weaponization、Delivery、Exploitation、Installation、Command & Control、Actions。對應六項原則（risk analysis、comprehensive security、defense in depth、weakest link analysis、single points of takeover、least permissions）。例如：
    - Least permissions：供應商憑證不應能進到 POS 網路。
    - Defense in depth：只靠單一層防護，被繞過就失守。
    - Comprehensive security：供應商也是攻擊路徑，需納入防護。
    - 另外要指出 Target 收到反入侵軟體警告卻沒處理。
- **B.** Threat environment 是外部威脅的總和，Plan 是依威脅制定計畫與原則，Protect 是實施存取控制、防火牆、加密等防護，Respond 是在攻擊發生時偵測、通報、處置。因為沒有任何防護百分之百有效，所以必須有事件回應機制。
- **C.** 至少涵蓋速度、availability、latency、jitter、error rate 之一。條文寫成 worst-case，例如「在 99.9% 的時間，單向 latency 不超過 150 ms」。Jitter 重要的原因是它讓即時語音斷續。Momentary peaks 讓 switch 緩衝區排隊，造成 latency 與 jitter，緩衝滿時封包遺失。對策是 overprovisioning、priority、reservation。
- **D.** 重點：
    - Switching table 以目的 MAC 查出口 port。
    - 階層式只有一條路徑，所以任何一處故障就中斷。
    - 加備援 link 會形成 loop。
    - RSTP 偵測並封鎖多餘的 port，主路徑失效時再快速啟用備援。
