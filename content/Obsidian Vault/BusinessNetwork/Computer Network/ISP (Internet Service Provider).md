### Def
- 提供使用者或組織連上網際網路的業者
- 自己營運網路(一個或多個AS)，透過與其他網路互連把使用者流量送往全球網際網路
- note：AS Autonomous System
	- 網際網路由數萬個AS構成，以BGP (eBGP)互連

Ex. 中華電信(Hinet)、台灣大哥大...

### Last mile技術
- FTTH：光纖(GPON/ XGS-PON)
- VDSL/ ADSL：銅線電話線
- Cable：同軸電爛
- 4G/5G：無線

|      | 第一類電信事業                       | 第二類電信事業                          |
| ---- | ----------------------------- | -------------------------------- |
| 核心特徵 | 自薦持有電信網路                      | 不設置電信網路，租用第一類業者網路設施              |
| 網路設施 | 機房、光纖、基地台,..                  | 像第一業者租用                          |
| 典型代表 | 中華電信、台灣大哥大、遠傳、台灣之星、亞太電信、台灣固網等 | 多數小型 ISP、MVNO（行動虛擬網路業者）、網路電話服務商等 |
