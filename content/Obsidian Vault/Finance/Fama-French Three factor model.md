- 規模因子 Small Minus Big
	- note: Size effect 規模性應
		- 小市值公司長期平均報酬率高於大市值公司
- 價值因子 Value Effect
	- note: Value Effect 價值效應
		- 高帳面市值比($B/M$ Book to market ratio)平均報酬率高於低帳面市值比
			- note: Book to Market ratio
				- 公司帳面價值 / 市場總價值
				- 高：市場低估（價值股）
				- 低：市場給較高估值（成長股）
