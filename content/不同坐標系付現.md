## 階段 1：資料前處理（最耗時、最多手動步驟）

⚠️ 這階段大多數步驟需要 HPC 上的真實資料路徑（`/OFS/nwpr/laps/com217/...`）與 Fortran 執行檔，本機通常無法完整跑通，建議在 ln 主機上執行。

**1-1. PPI 管線（Polar 分支）**

```bash
python ppi_processing/select_light.py          # 事件篩選，Top-K=2000
python ppi_processing/group_tiemseries.py       # 時間窗合併
python ppi_processing/generate_script.py        # 產生 .ksh，之後手動用 ksh 跑 reduce_res.exe（Fortran）
python ppi_processing/combined_polar.py         # 裁切成 (15,360,200) 訓練陣列
python ppi_processing/calcalate_height.py       # 波束高度靜態計算（只需算一次）
```

**1-2. CAPPI 管線（Cartesian 分支）**

```bash
python ppi_processing/generate_casetime_list.py
# → 之後由 ppi2cappi_provide/workdir/cappi_rerun.ksh 呼叫 ppi2cappi.exe（Fortran）
python cappi/main.py                            # 二進位 → radar_cappi_3D.npy
```

**1-3. .npy → HDF5 快取（兩支都要跑）**

```bash
python data_processing/data_caching_polar.py
python data_processing/data_caching_cartisan.py
```

- 這步用 `processed_files.pkl` 記錄進度，可中斷續跑。
- 完成後，`data_processing/cache/` 底下應該有 `polar_resolution_2020~2025.h5` 與 `cappi_resolution_2020~2025.h5`。

**1-4.（可選但建議）驗證切分邏輯**

```bash
python data_processing/plot_monthly_from_h5.py
```

畫出 `monthly_distribution.png`，確認月份切分正常再往下走。

**1-5.（可選）選層分析** 若要重現 `GroupD_mRMR` 組合的選層依據：

```bash
cd feature_selection
python analyze_elevation_correlation.py       # SEED=42
python analyze_height_correlation_cappi.py    # SEED=42
```

（見 [03](https://claude.ai/chat/03_%E7%89%B9%E5%BE%B5%E9%81%B8%E5%B1%A4%E5%88%86%E6%9E%90_feature_selection.md)）這步只是「解釋」mRMR 為何選那三層，不影響後續訓練能否跑，可以先跳過。

## 階段 3：正式訓練（需送 HPC GPU）

**建議順序**（依 [10](https://claude.ai/chat/10_%E8%AB%96%E6%96%87%E5%AF%A6%E9%A9%97%E5%B0%8D%E7%85%A7%E7%B8%BD%E8%A1%A8.md) §3）：

**3-1. Polar 仰角實驗**（4 組：CMAX / GroupA_E02 / GroupB_E02_E09 / GroupC_E01_E02_E03）

```bash
python main_ddp_simvp_elevation_polar.py
```

前提：`data_processing/cache/` 有 Polar HDF5 快取；`TARGET_GROUPS` 控制這次要跑哪幾組（見 [04](https://claude.ai/chat/04_%E6%A5%B5%E5%BA%A7%E6%A8%99%E4%BB%B0%E8%A7%92%E8%A8%93%E7%B7%B4%E8%88%87%E8%A9%95%E4%BC%B0.md)）。

**3-2. Cartesian/CAPPI 高度層實驗**（5 組）

```bash
python main_ddp_simvp_elevation_cartisan.py
```

確認 `TARGET_GROUPS = ["GroupA_3km", "GroupB_1_2_3km", "GroupC_low_mid_high", "GroupD_mRMR", "GroupBase_CMAX"]` 全開（見 [05](https://claude.ai/chat/05_%E7%AC%9B%E5%8D%A1%E7%88%BECAPPI%E8%A8%93%E7%B7%B4%E8%88%87%E8%A9%95%E4%BC%B0.md)）。

**3-3. DiffCast 殘差擴散**

```bash
python main_ddp_simvp_diffcast_cartisan.py
```

⚠️ 前提：3-2 的 `GroupC_low_mid_high` 權重要先訓練完，DiffCast 會拿它當 `mu_ckpt`（deterministic backbone）（見 [07](https://claude.ai/chat/07_%E6%AE%98%E5%B7%AE%E6%93%B4%E6%95%A3_DiffCast.md)）。

**如何送上 HPC**：把要跑的指令放進 `.sh` 腳本（參考 `polar_simvp.sh` 格式），在 ln 主機上：

```bash
pjsub 檔案.sh
```

用 `pjstat --all | grep unlimited` 追蹤，`chkgpu` / `nvidia-smi` 看 GPU 狀態（見 [15](https://claude.ai/chat/15_HPC%E4%BD%9C%E6%A5%AD%E6%8F%90%E4%BA%A4.md)）。訓練時間長就用 `pjsub` 排程，不要用 `pjinterbig` 硬撐（上限 24 小時）。

**驗證訓練沒壞**：三支主程式都沒有內建「跑一個 batch 就停」的 debug flag，可以先手動改小 `epochs`/資料量跑一次，確認 loss 正常、`best_model_*.pth`/`resume_*.pth` 有正常寫出，再改回正式設定。
