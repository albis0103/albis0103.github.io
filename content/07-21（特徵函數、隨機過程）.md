
# 特徵函數（Characteristic Function）

## 定義

設隨機變數 $X$，其特徵函數定義為：

$$\varphi_X(t) = E[e^{itX}] = \int_{-\infty}^{\infty} e^{itx} , dF_X(x), \quad t \in \mathbb{R}$$

其中 $i$ 為虛數單位。對離散型隨機變數：

$$\varphi_X(t) = \sum_k e^{itx_k} P(X = x_k)$$

本質上是機率分布的傅立葉變換（差一個負號慣例）。

## 基本性質

- **存在性**：對任意隨機變數恆存在，因為 $|e^{itX}| = 1$，積分絕對收斂（不像動差生成函數 MGF 可能不存在）
- $\varphi_X(0) = 1$
- $|\varphi_X(t)| \le 1$ 對所有 $t$
- 共軛對稱：$\varphi_X(-t) = \overline{\varphi_X(t)}$
- **一致連續**於整個實軸

## 與動差的關係

若 $E[X^n]$ 存在，則：

$$\varphi_X^{(n)}(0) = i^n E[X^n]$$

即可透過在原點的泰勒展開逐階微分取得各階動差：

$$\varphi_X(t) = \sum_{n=0}^{\infty} \frac{(it)^n}{n!} E[X^n]$$

## 獨立和的性質（核心用途）

若 $X, Y$ 獨立，則：

$$\varphi_{X+Y}(t) = \varphi_X(t) \cdot \varphi_Y(t)$$

這是特徵函數最關鍵的性質——把卷積問題轉成乘法問題，中央極限定理的證明主要依賴此性質。

## 反演公式（Fourier Inversion）

給定 $\varphi_X$ 可唯一還原分布（一一對應）：

$$f_X(x) = \frac{1}{2\pi} \int_{-\infty}^{\infty} e^{-itx} \varphi_X(t) , dt$$

（連續型且 $\varphi_X$ 可積時成立）

## 常見分布範例

|分布|特徵函數|
|---|---|
|$N(\mu, \sigma^2)$|$\exp(i\mu t - \tfrac{1}{2}\sigma^2 t^2)$|
|$\text{Poisson}(\lambda)$|$\exp(\lambda(e^{it}-1))$|
|$\text{Exp}(\lambda)$|$\dfrac{\lambda}{\lambda - it}$|
|$\text{Bernoulli}(p)$|$1-p+pe^{it}$|

## 為何優於 MGF

動差生成函數 $M_X(t) = E[e^{tX}]$ 可能發散（例如重尾分布），特徵函數用 $e^{itX}$ 代替 $e^{tX}$，模長恆為 1，積分必收斂，因此對任意分布都適用，這也是機率論中證明極限定理（CLT、Lévy 連續性定理）的標準工具。



## 隨機過程（Stochastic Process）

**定義**：一個隨機過程是一族隨機變數 ${X_t : t \in T}$，定義在同一機率空間 $(\Omega, \mathcal{F}, P)$ 上，其中 $T$ 是指標集（index set，通常代表時間）。對固定的 $\omega \in \Omega$，映射 $t \mapsto X_t(\omega)$ 稱為一條**樣本路徑（sample path）**。

### 分類維度

**依指標集 $T$：**

- 離散時間（$T = \mathbb{N}$）：如馬可夫鏈
- 連續時間（$T = [0,\infty)$）：如布朗運動、卜瓦松過程

**依狀態空間 $S$（$X_t$ 的值域）：**

- 離散狀態：如生死過程（birth-death process）
- 連續狀態：如布朗運動

### 核心性質

**1. 馬可夫性質（Markov Property）** $$P(X_{t+1} = j \mid X_t = i, X_{t-1}, \dots, X_0) = P(X_{t+1} = j \mid X_t = i)$$ 未來只依賴現在狀態，與過去路徑無關（無記憶性）。這是你已接觸過的 HMM 的基礎假設，差別在於 HMM 的真實狀態不可觀測，只能透過觀測序列推論。

**2. 獨立增量（Independent Increments）** 對任意 $t_1 < t_2 < \dots < t_n$，增量 $X_{t_2}-X_{t_1}, X_{t_3}-X_{t_2}, \dots$ 互相獨立。卜瓦松過程與布朗運動皆滿足此性質。

**3. 平穩性（Stationarity）**

- 嚴格平穩：$(X_{t_1},\dots,X_{t_n})$ 與 $(X_{t_1+h},\dots,X_{t_n+h})$ 同分布
- 弱平穩（共變異平穩）：僅要求均值與自相關函數對時間平移不變，$\text{Cov}(X_t, X_{t+h})$ 只與 $h$ 有關

**4. 鞅性質（Martingale）** $$E[X_{t+1} \mid \mathcal{F}_t] = X_t$$ 其中 $\mathcal{F}_t$ 是到時刻 $t$ 為止的資訊（filtration）。這是「公平賭局」的數學刻劃，在選擇權定價（風險中性測度）中是核心工具。

### 標準範例族

|過程|狀態空間|時間|關鍵性質|
|---|---|---|---|
|隨機漫步（Random Walk）|離散|離散|獨立增量、馬可夫|
|馬可夫鏈|離散|離散|轉移矩陣 $P$，Chapman-Kolmogorov 方程|
|卜瓦松過程|$\mathbb{N}$|連續|計數過程、獨立增量、$X_t - X_s \sim \text{Poisson}(\lambda(t-s))$|
|布朗運動（Wiener Process）|$\mathbb{R}$|連續|$X_0=0$，獨立增量，$X_t-X_s \sim N(0, t-s)$，路徑連續但處處不可微|
|高斯過程|$\mathbb{R}$|連續/離散|任意有限維邊際分布皆為多元常態，由均值函數與共變異函數（kernel）完全決定|

## 有限維分佈（Finite-Dimensional Distributions, FDDs）

### 定義

給定隨機過程 ${X_t : t \in T}$，對任意有限子集 ${t_1, \dots, t_n} \subset T$（$n \in \mathbb{N}$），聯合機率分布 $$F_{t_1,\dots,t_n}(x_1,\dots,x_n) = P(X_{t_1} \le x_1, \dots, X_{t_n} \le x_n)$$ 稱為該過程的一組**有限維分佈**。所有這樣的分布族 ${F_{t_1,\dots,t_n} : n \in \mathbb{N},, t_1,\dots,t_n \in T}$ 合稱為過程的**有限維分佈族**。

### 為何重要：Kolmogorov 存在定理

因為 $T$ 通常不可數（如 $T = [0,\infty)$），無法直接對整個樣本路徑空間指定機率測度。**Kolmogorov 擴張定理**指出：只要有限維分佈族滿足以下兩個一致性條件，就存在唯一的機率測度 $P$（在適當的乘積 $\sigma$-代數上），使得對應的隨機過程恰好具有這組有限維分佈。

**一致性條件（Consistency Conditions）：**

**1. 對稱性（Permutation consistency）** 對任意排列 $\pi$， $$F_{t_{\pi(1)},\dots,t_{\pi(n)}}(x_{\pi(1)},\dots,x_{\pi(n)}) = F_{t_1,\dots,t_n}(x_1,\dots,x_n)$$

**2. 邊際一致性（Marginalization consistency）** $$F_{t_1,\dots,t_n}(x_1,\dots,x_{n-1},\infty) = F_{t_1,\dots,t_{n-1}}(x_1,\dots,x_{n-1})$$ 即高維分布對某一維取邊際，須與低維分布一致。

這兩條件合稱 **Kolmogorov 一致性條件**，是建構隨機過程的理論基礎——你不需要直接定義樣本路徑的機率結構，只需指定所有有限維分布即可。

### 關鍵限制

有限維分佈**不能**唯一決定樣本路徑的**整體性質**，例如：

- 連續性（continuity）
- 可微性
- 上確界/下確界的分布

這些是**依賴於不可數多個時間點**的性質，屬於機率測度在路徑空間（如 $C[0,\infty)$）上的性質，超出有限維分佈的資訊範圍。**布朗運動的路徑連續性**就是一個經典例子：Kolmogorov 延拓定理只保證存在一個機率測度使 FDD 相符，但要保證存在一個「路徑處處連續」的版本，需要額外的 **Kolmogorov 連續性定理**（依賴增量的矩估計，如 $E|X_t - X_s|^{2k} \le C|t-s|^{1+\epsilon}$）。

### 具體例子

**布朗運動的有限維分佈**：對 $0 = t_0 < t_1 < \dots < t_n$， $$(X_{t_1}, X_{t_2}-X_{t_1}, \dots, X_{t_n}-X_{t_{n-1}}) \sim N(0, \text{diag}(t_1-t_0, \dots, t_n-t_{n-1}))$$ 獨立增量結構使聯合分布可以直接由增量的邊際分布乘積給出，這是驗證一致性條件最直接的情形。

**高斯過程**：FDD 完全由均值函數 $m(t)$ 與共變異函數 $k(s,t)$ 決定， $$(X_{t_1},\dots,X_{t_n}) \sim N(\mathbf{m}, \mathbf{K}), \quad K_{ij} = k(t_i,t_j)$$ 這也是為什麼高斯過程在機器學習（GP regression）中只需指定 kernel 函數即可定義整個過程。
