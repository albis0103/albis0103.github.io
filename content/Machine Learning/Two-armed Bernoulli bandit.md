雙臂伯努利賭博機**是強化學習（Reinforcement Learning）與機率統計中最基礎且經典的**「探索與利用」（Exploration vs. Exploitation）決策模型。

by [[Stochastic Multi-Armed Bandit]]

### 1. 基本設定與運作機制

想像你面前有兩台拉霸賭博機（Arm 0 與 Arm 1）：
- **兩支手臂（Two Arms）：** 每次決策你必須選擇拉動 Arm 0 或 Arm 1。
    
- **伯努利獎勵（Bernoulli Reward）：** 每次拉動手臂的結果只有兩種：**成功（獲得獎勵 1）** 或 **失敗（獲得獎勵 0）**。
    - 拉動 Arm 0 獲得獎勵 1 的機率為 $p_0$
    - 拉動 Arm 1 獲得獎勵 1 的機率為 $p_1$
    
- **未知參數（Unknown Parameters）：** 決策者事前**不知道** $p_0$ 與 $p_1$ 的真實數值。
    

### 2. 核心矛盾：Exploration vs. Exploitation

在有限的嘗試次數（例如拉動 $N$ 次）內，你的目標是極大化累積獲得的總獎勵。這會產生嚴重的兩難：


- **利用（Exploitation）：** 選擇目前「歷史勝率最高」的手臂，以獲取當前估算出的最大期望收益。
    
- **探索（Exploration）：** 選擇目前嘗試次數較少、勝率不明的手臂，以收集更多資訊，確定它是否其實比另一支手臂更好。
    
如果只做 Exploitation，可能因為初期幾次抽樣的運氣不佳，而永久放棄了真正期望值較高的地方；如果過度 Exploration，則會浪費太多次數在劣質手臂上。


### 3. 常見解決演算法

為了解決這個兩難，常見的策略包括：

1. **$\epsilon$-Greedy（$\epsilon$-貪婪法）：**
    
    - 設定一個小機率 $\epsilon$（例如 $0.1$）。
        
    - 以 $1 - \epsilon$ 的機率選擇目前平均獎勵最高的手臂（利用）。
        
    - 以 $\epsilon$ 的機率隨機選擇任一手臂（探索）。
        
2. **UCB1（Upper Confidence Bound, 上信賴區間法）：**

    - 為每支手臂計算一個估計值的**不確定性上限**。
        
    - 選擇「估計期望值 + 不確定性加成」最高的手臂。嘗試次數較少的手臂會獲得較高的不確定性加成，從而自動觸發探索。
        
3. **Thompson Sampling（湯普森採樣 / 貝氏方法）：**
    
    - 對 $p_0$ 與 $p_1$ 分別維護一個 Beta 分配作為先驗機率（Prior）。
    
    - 每次決策時，從兩個 Beta 分配中各自抽樣出一個機率值，並選擇抽樣值較大的手臂拉動。根據結果（1 或 0）使用貝氏定理更新該手臂的 Beta 分配。
        

### 4. 衡量標準：Regret（後悔值）

衡量演算法好壞的核心指標是 **Regret（累積後悔值）**。

若已知最佳手臂的勝率為 $p^* = \max(p_0, p_1)$，則拉動另一支手臂會產生期望損失（Gap）。一個優秀的演算法應該讓 Regret 隨著時間 $T$ 增長的速度越慢越好（例如達到對數級增長 $O(\log T)$）。
