## 研究問題

- 作者想解決什麼問題？

- Problem:
	- 以往資料皆使用笛卡爾坐標，座標系統為系統比較過
		- PPI 極座標是雷達站原始掃描格式；CAPPI 則是原始資料經插值後投影到固定物理高度網格。
		- 雷達觀測特性：離站越近資料越密集，越遠越稀疏；經插值轉換後，密集區域（近站）影響不大
		![[radar_polar_scan_density.svg|373]]
	- 三維回波資料只被證實在CAPPI會改善預報穩定性，**無法區分是垂直資訊還是內插後資料影響**
	- 驗證殘差擴散在應用在CAPPI是否改善模糊化問題
- 為什麼這個問題重要？
	- 	目前預報方法
		- **NWP 數值天氣預報**：適合中長期預測，[[NWP(Numerical Weather Predict; 數值天氣預測)]]
		- **雷達回波外推**：短時效（0–2 小時內）的主要方法，忽略回波在生成、發展、消散過程中的強度演化。[[雷達回波外延法]]
	- 深度學習雷達外推近年演進三階段：
    1. 時空確定性回歸模型（如 ConvLSTM 等）因以 MSE（學習多種降水型態的均方誤差），預測時效長趨於模糊平滑。
    2. 生成式模型（如 PGMR、UPS 等），能緩解模糊化，但訓練不穩定、成本高；且過去資料多將多高度回波壓縮成二維單一平面，遺失高度動態資訊（受限於當時運算成本）。
    3. 近年運算能力提升，開始有能力使用三維體積資料。

## 方法與模型
(使用哪些模型、流程或系統設計？)
- Input
	- Training Data: 前10 timestamps , Testing Data: 後10 timestamps
	- Pre-Process
		- CAPPI Transformation : Adaptive Barnes Interpolation
		- Mask
			- Dynamic: 真實環境無降水($-99dBz$) 
			- Fixed：雷達觀測盲區，無效資訊($-999dBz$)
		- Data Selection：塞選強降雨
			- $W_t=\sum(Z_t, i)^2$ ，每年塞選 Top-1000 $W_t$ 值, each資料擴展至前後3 hr
		- Data Split：以月份切割，再以事件切割（間隔 > 60 mins)
			- Train: Val = 8:2, Test: 2025獨立資料
- Model: Diffcast Framework![[Nite 5.jpeg]]
	- Deterministic: SimVP $\rightarrow \text{output:}\mu$
		- Temporal Aware Elev Fusion(Encoder):
			- input: $X\in \mathbb{R}^{B \times T \times C \times D \times H \times W}, D$為仰角層數
			- process:
					 ![[Nite 2.jpeg|466]]
				- Single Elev Encoder($\times N_{Elev}$): convolution per each elevation, 
					output $(F_1, \cdots, F_{N_{Elev}})$ 
					1. Circular Padding: $x_{padded}[:, :, H+1, :]=x[:, :, 0, :], x_{padded}[:, :,0, :]=x[:, :, -1, :]$
					2. Circular Convolution($180 \times 200 \rightarrow 90 \times 100$) output $N_{Elev}$ Frames
				- Temporal Gate: 輸出 Temporal Score $T_i$, used $1 \times 1 \text{Conv}$
				- Spatial Router: 輸出 Spatial Score $S_i$ , used $1 \times 1 \text{Conv}$
				- Weight Score $w_i(x, y)$ : 給各仰角 weight score, 表示 $i$ 仰角貢獻資訊量
					$w_i(x, y)=softmax(z_i)=\frac{exp(z_i)}{\sum_j exp(z_j)}, z_i(x, y)=T_i+S_i$ 
			- output: 單一特徵圖$F_{fuse}(x, y)\sum_{i=1}^{N_{Elev}}w_i(x, y)F_i(x, y)$ 
			- Loss: $\mathcal{L}=\mathcal{L}_{det}+\lambda_{cls}\mathcal{L}_{cls}+\mathcal{L}_{diff}$ 
				- regression loss: 
					- FACL: 傳統MSE預測未來狀態各點期望值，會壓抑高頻細節，對預測場與真實場分別做FFT，比較兩者
					- Dice Loss: 常用於處理類別不平衡問題
						- $\mathcal{L}_{Dice}(m, m_{true})=1-DSC=1-\frac{2\sum_ip_ig_i}{\sum_ip_i^2+\sum g_i^2+\epsilon}$
							- 預測: $p_i$
							- 真值: $g_i$ 
					- 擴散去噪 Loss: 用$MSE(\epsilon, \hat\epsilon)$
		- Temporal Attention: 對 $T$ 軸 self-attention
			- input $X \in \mathbb{R}^{B \times T \times C \times H \times W}$
			- process
				- $X' \in \mathbb{R}^{ T \times C \times (B* H * W)}$ , $C$: each pixel特徵的向量長度 ![[Nite 3.jpeg|349]]
				- then reshape $\rightarrow \mathbb{R}^{C_{hid} \times B \times H \times W}, C_{hid}=T\times C$ 
		- MidInception
			- 降維($1\times 1\;Conv$ )：$C_{hid}=\frac{C_{hid}}{2}$ 
			- Inception:(UNet like structure)
				![[Nite 4.jpeg|256]]
				- total branch = Number of kernel size (4) $\times$ 3 branch = 12
				- output: $(out_1, \cdots, out_{12})$
			- Branch_router: 依each kernel size 適合機率做加權分數
				$w_i=softmax(logit_i),\; logit_i(h, w)=\sum_{c=1}^{C_hid}W_ix_i(h, w)+bi$
			- output:  $y=\sum_{k=1}^{12}w_kout_k$ 
		- Decoder: $90 \times 100 \rightarrow 180 \times 200$ 
	- Stochastic: GTUNet: 預測對應時間 $t$ 的noise，輸出確定性模型與殘差預測相加：$\hat y = \mu + \hat r$ 
跨座標/跨垂直配置的比較，模型結構完全不變，只換輸入的座標系統與垂直層數。

## Metrics
(用哪些指標？, 是否足以回答研究問題？)
指標
- CSI: 有降水預測整體表現，越大越好
- POD: 降水事件被正確捕捉比例（命中率）
- FAR: 誤報比例，越低越好
- Bias: 降水事件的捕捉能力
- RMSE: 數值誤差
- FSS: 鄰域超過閾值比例的相似度
是否足以回答問題
- 足夠：CSI2-/ RMSE/ FSS 對應 “偵測”與 “重建” ，呼應結論：極座標抓的準，CAPPI畫的準
## Ablation / Robustness
(是否有消融實驗？, 是否有穩健性測試或錯誤分析？)
消融實驗
- 垂直配置消融：及座標仰角組合 v.s. CAPPI高度層組合，以最大合成回波為基準，並跑 mRMR 統計分析找出相關性或互補性較強的組合，並驗證密集仰角輸入是否帶來效益。
- CMAX層數消融：依“垂直配置實驗”中最佳配置對坐標系比較，兩座標呈現明確互補權衡，並非單一座標全面佔優。
- 殘差擴散：在前實驗選出的最佳座標配置下，引入殘差擴散，改善模糊化，前提是確定性模型本身預測趨勢正確。
穩健性測試
：用 Block Bootstrap（63 個日區塊）三個天氣型態的個案（對流/梅雨/冬季鋒面）做統計檢定，用交叉驗證主結論在不同系統下是否一致，這比單純報全測試集平均數要嚴謹。

## Limitation
(作者承認哪些限制？, 還有哪些未說明的限制？)
1. 結論建立在 SimVP 骨幹上，換架構（ConvLSTM/Transformer類）是否成立未驗證。
2. 評估只到20/40 dBZ、空間尺度只到5km，未做更細緻的敏感度分析。
3. 單站資料（五分山），權重無法直接移植到其他雷達站。
4. 測試集僅2025一年，且無颱風個案。
5. 殘差擴散推論成本高（約確定性模型50倍），離即時作業化部署仍有落差。
## 可改進處
(若由自己延伸，應補哪些資料、實驗或討論？)
- 補颱風個案，驗證極端強對流下「極座標抓得準/CAPPI畫得準」是否還成立（颱風尺度介於對流與鋒面之間）。
- 加入機率校準指標，讓殘差擴散模組的評估方式對得上它本質是生成式/機率模型這件事。
- 對隨機種子跑多次重複，報告結論的變異範圍，而不是單一 seed 的結果。
